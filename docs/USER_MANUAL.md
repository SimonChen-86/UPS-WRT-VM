# UPS-WRT-VM 智能联动与供电中心 - 系统使用说明书

本说明书面向需要深入理解系统工作机制、接入多台局域网从机（群晖 NAS、PVE、Windows 工作站）以及进行个性化参数精细调优的用户。

---

## 一、 动态图形遥测仪表盘深度解读

打开软路由后台：**【服务】➔【UPS-WRT-VM 智能联动】**，页面首屏即为纯 CSS/SVG 开发的现代化实时监控仪表盘：

```text
┌─────────────────┬─────────────────┬─────────────────┬─────────────────┐
│   电池当前电量   │  预计可用续航    │   市电电网质量   │   实时供电状态  │
│      100%       │   4 小时 38 分  │      224.0 V    │  市电正常 (OL)  │
│  (动态环形进度)  │ (按当前负载测算) │ (市电输入电压)  │  (动态脉冲呼吸灯)│
└─────────────────┴─────────────────┴─────────────────┴─────────────────┘
```

1. **电池当前电量 (Battery Charge)**：
   - 动态双色环形仪表盘，数字与指针每 3.5 秒异步无感局部刷新；
   - **智能颜色预警**：
     - `> 50%`：健康翠绿色；
     - `20% ~ 50%`：注意警戒橙色；
     - `< 20%`：低电量告警红色。
2. **预计可用续航 (Runtime Remaining)**：
   - 后端根据 UPS 硬件内置的实时放电积分算法测算（`battery.runtime`），动态换算为易读的“小时 + 分钟”；
   - 随宿主机负载波动实时变化，为您评估是否需要拉长或缩短关机倒计时提供最直观的科学参考。
3. **市电电网输入 (Input Voltage)**：
   - 实时遥测入户市电端电压（如 220V ~ 230V）；
   - 遇断电或欠压跳闸时，读数即刻跌为 `0.0V`。
4. **实时供电状态与后台哨兵**：
   - **脉冲呼吸指示灯**：绿色脉冲闪烁表示市电在线（ONLINE）；切入电池供电时指示灯立即转为鲜红高频警报；
   - **哨兵状态**：实时显示底层 `upsmon` 守护进程 PID 与当前是否正处于断电防抖倒计时之中。

## 二、 多设备共享接入：NUT 账户表格式管理

软路由作为家庭与实验室的 **UPS Master 核心主机**，支持局域网内的其它设备（如群晖 NAS、PVE 节点、Windows 电脑）作为 **Slave 从机** 同步接入，实现“一台 UPS 保护整网多台物理机”。

### 1. 账户管理操作指南
在页面中部的【NUT 访问凭据与多设备共享管理】表格中：
- **查看与添加账户**：
  点击表格上方的 **【➕ 添加 NUT 账户】** 按钮，在弹出窗口中输入：
  - 用户名（例如 `synology` 或 `pve_node`）；
  - 密码（支持在表格中点击 👁 图标一键明文/掩码切换）；
  - 权限角色：普通从机监控 (slave) 或 管理员全权 (admin)。
- **指定主监控凭据**：
  表格右侧单选框可指定一个账号作为当前软路由本地哨兵（`upsmon`）的连接账户；
- **自动热生效**：
  点击页面底部【保存并应用】后，系统会自动将表格数据同步双向写入 `/etc/config/nut_server` 与 `/etc/config/nut_monitor`，并平滑重启服务，**无需重启软路由**。

---

### 2. 实战案例：接入群晖 Synology NAS 作为从机

1. **在软路由添加专用账户**：
   在表格中添加一个账户：用户名 `synology`，密码 `syno123456`，角色选择 `普通从机监控 (slave)`，保存生效；
2. **在群晖 DSM 后台设置**：
   - 打开群晖 DSM 网页后台：**【控制面板】➔【硬件和电源】➔【常规】➔【不间断电源 (UPS)】**；
   - 勾选 **【启用 UPS 支持】**；
   - 网络不间断电源类型：选择 **【Synology 不间断电源服务器】**；
   - 网络不间断电源服务器 IP 地址：填入软路由的 IP 地址（如 `192.168.1.1`）；
   - 点击【设备信息】，群晖即可成功读取到电量、型号与电压！
   - 设置群晖进入安全模式的时间（例如“进入待机模式前的等待时间: 5 分钟”）。

## 三、 断电防抖与双阶段分级关机策略配置

在页面的【分级关机与安全联动编排策略】板块中，提供以下 5 个核心参数：

| 参数项 | 推荐设定值 | 详细作用与运维调优建议 |
| :--- | :---: | :--- |
| **启用智能联动保护** | `开启` | **一键暂停/启用总开关**。家庭电路改造、插座拔插测试或电网调试时，可随时一键关闭，系统将仅在日志中记录事件，绝不触发关机。 |
| **市电恢复等待时间** | `180 秒` | **断电防抖倒计时**。针对雷雨天气或电网频繁闪断波动，UPS 切换到电池后先静候倒计时。若在此时间内来电，系统自动撤销关机流程并归档日志。 |
| **业务机落盘超时** | `150 秒` | **业务虚拟机优雅关机最大保护时间**。ESXi 会向非路由的业务机（如 Windows Server/数据库）发送优雅关机信号并每 2 秒轮询一次。若全部提前关停则立刻推进，若个别机器卡死，超时后执行保底断电。 |
| **低电量即时触发** | `开启` | **极端防亏电熔断保护**。若因电池老化突发跳水触发 `LOWBATT`，系统将跳过防抖倒计时，立即提前触发全套安全关机，规避硬件损坏。 |
| **ESXi 宿主机地址** | `实际 IP` | 目标虚拟化宿主机的内网管理 IPv4 地址。 |

## 四、 全链路持久化运行与关机审计日志

本项目具备企业级灾备系统的审计追溯能力：

- **持久化设计**：
  软路由日志存放于 `/etc/ups_manager/ups_events.log`（位于 `/overlay` 物理闪存分区），断电再开机**永不丢失**，同时在 `/var/log/ups_events.log` 建立软链接兼容系统监控；
  ESXi 关机轨迹存放于 VMFS 持久化存储卷同级目录下 `ups_shutdown.log`。
- **全事件追踪覆盖**：
  - `[WARN]` 市电中断告警与端电压遥测；
  - `[INFO]` 防抖倒计时启动与剩余秒数；
  - `[ONLINE]` 市电恢复供电与倒计时进程撤销；
  - `[CRITICAL]` 双阶段分级优雅关机时序轨迹；
  - `[CONFIG]` 管理员修改参数与账户的全字段变更记录；
  - `[DIAG]` 协议认证与 SSH 通路测试日志。
- **界面运维**：
  在 Web 控制台底部可直接浏览最新日志，支持实时刷新与一键清空日志历史。
